Declared caches: SYN-TUBE-MTP and SYN-TUBE-MHP. Mini-RF, SELENE LRS, and GRAIL stay unfetched.

Fail-closed: dark first, then pinch, then stub, then clutter. Equality sits. Width None skips pinch. Length None skips stub.

Parent instruments: Mini-RF S-band 2380 MHz side-looking SAR vs LRS 5 MHz nadir sounder. Mixing them silently is a lie.

Mini-RF hybrid-pol Stokes S1–S4 and CPR are named, not scored. LRS tanδ ~0.016 → ~6 dB/km and ε=1 / ε=4 depths are named, not scored. Processing is not a walk.
